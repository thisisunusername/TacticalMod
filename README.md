# TacticalMod

一款 **Minecraft 1.21.4 (Fabric)** 的战术护甲拓展模组，添加经典战术装备。
 
## 新增装备

| 装备 | 描述 |
|------|------|
| **S70 Elite Tactical Helmet** | S70 精英战术头盔 |
| **Titan Chestplate** | 泰坦胸甲（重型，**穿上后禁用腿部 & 脚部槽位**）|

## 环境要求

- Minecraft：**1.21.4**
- 加载器：**Fabric**（fabric-loader ≥ 0.15.0）
- 依赖：**Fabric API**（≥ 0.96.0）
- Java：≥ 21

./gradlew build
